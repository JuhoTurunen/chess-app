# User Manual

## Login
On launch, the application displays a login screen. Enter a username (1-50 alphanumeric characters) to continue. New usernames are automatically registered; returning users are recognized and their statistics are restored.

## Main Menu
From the main menu, select a game mode:

- **Player vs Player** — Two players take turns on the same computer. The board flips after each move to show the current player's perspective.
- **Player vs AI** — Play against the chess engine. Select your color (white or black) and difficulty level (Easy, Medium, or Hard).

The bottom of the screen displays your win/draw/loss record against the AI, broken down by difficulty.

## Gameplay
Click a piece to select it (highlighted), then click a destination square to move. Invalid moves are automatically rejected. The game enforces all standard chess rules including castling, en passant, promotion, and the 50-move draw rule.

When playing against the AI, it responds immediately after each move. The game ends automatically upon checkmate, stalemate, or draw.

Use the **Menu** button in the top corner to return to the main menu. Note: leaving a game in progress will discard it.
